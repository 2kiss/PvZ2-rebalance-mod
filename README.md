# PvZ2 Night Carnival: мод без доната

Мод для Plants vs. Zombies 2 (iOS, версия 13.5.1). Готовые IPA в репозиторий не кладутся, здесь только инструменты, которые собирают мод из твоей копии игры.

## Что меняет мод

- **Night Carnival.** Новая вкладка магазина, она открывается первой. В ней 4 слота со случайными премиум-растениями со скидкой, и каждые 8 часов набор меняется. На карточке: название растения, размер скидки и старая цена (`-40%  was 75,000`), плюс метка SALE и таймер.

  | Слот | Какие растения | Скидки |
  |---|---|---|
  | A | все премиум | 20–30% |
  | B | все премиум | 35–45% |
  | C | epic и legendary | 50–55% |
  | D | только legendary | 60–70% |

- **Вкладка «Растения».** Все 59 премиум-растений за монеты по полной цене:

  | Тир | Цена |
  |---|---|
  | rare | 40 000 |
  | mint | 60 000 |
  | epic | 75 000 |
  | legendary | 120 000 |

  Растения, которые у тебя уже есть, не предлагаются (кроме 4, для которых в игре нет такого правила).
- **Донат вырезан.** Всё, что стоило реальных денег, теперь продаётся за игровую валюту:
  - обычные товары: $1 = 25 алмазов;
  - пачки алмазов за монеты: 300 монет за алмаз;
  - пачки монет за алмазы: 250 монет за алмаз.
- **Монеты:** серебряная 10 → 15, золотая 100 → 150.
- **Вшитые чужие библиотеки** (чит-меню iOSGods, iGameGod, dylib сайта ipaomtk) удаляются из IPA.

Все цифры настраиваются в [`mod/config.json`](mod/config.json).

## Сборка

```
python3 tools/build_mod.py PvZ2.ipa PvZ2-NightCarnival.ipa
```

Нужен Python 3.8+, сторонние библиотеки не требуются. На вход подаётся расшифрованная IPA версии 13.5.1.

## Установка на iPhone

IPA приходит неподписанной. Подписать и поставить её можно одним из способов:
- TrollStore;
- подписывальщик на телефоне: ESign, Scarlet, Feather;
- AltStore или SideStore (нужен компьютер).

У мода свой bundle ID (`com.popcap.ios.PvZ2.carnival`), так что он ставится отдельным приложением рядом с оригинальной игрой. Прогресс у него свой; его можно перенести через вход в аккаунт EA.

## Известные риски (на устройстве ещё не проверено)

- Вкладку карнавала и покупку растений за монеты игра раньше не использовала. Данные собраны по образцу родных товаров, но работу видно только в самой игре.
- Не все растения вшиты в игру. Графику примерно 280 растений и некоторых миров игра докачивает при первом использовании, для этого нужен интернет.
- В сети игра может скачать с серверов EA обновлённый `main.rsb` и использовать его вместо модифицированного. Тогда мод перестанет работать.

## Инструменты

- `tools/pvz2/rsb.py`: чтение и пересборка RSB (`1bsr` v4) и пакетов RSG. Пересборка без изменений даёт байт-в-байт тот же пакет.
- `tools/pvz2/rton.py`: конвертер RTON ↔ JSON. Все 5219 файлов из `Packages` пересобираются байт в байт.
- `tools/pvz2/macho.py`: удаление внедрённых `LC_LOAD_DYLIB` из бинарника.
- `tools/build_mod.py`: сборка мода.
